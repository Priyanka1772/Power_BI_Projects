## Financial Performance Dashboard - Power BI Project
## Project Summary
* Developed an interactive Power BI report view for comprehensive financial performance analysis of a general business.
* Aims to provide key insights into revenue, expenses, and profitability, enabling data-driven decision-making.

## Features
* Dynamic Overview: Provides at-a-glance visualization of core financial metrics.
* Trend Analysis: Visualizes financial trends over time (e.g., profit by year, quarter and month) through interactive charts, allowing for the identification of seasonality and underlying performance shifts.
* Time-Based Slicers: Features intuitive Year and Month slicers, enabling users to dynamically filter all reports and focus on specific time periods for granular analysis.
* Interactive Insights: Allows users to explore financial data across various dimensions like Product, Segment to uncover performance drivers and areas for improvement.
* Interactive Geographical Analysis: Displays geographical profitability across different Countries, allowing for quick identification of high-performing and underperforming areas.

## Technologies Used
* Microsoft Power BI Desktop: For data modeling, visualization, and interactive report view creation.
* Microsoft Power BI Service: For publishing and understanding pipeline and dataflows.

## How To Access
* The Power BI report (.pbix) file for this project has been uploaded to this repository.
* Download the file and open it with Microsoft Power BI Desktop to explore the interactive dashboard locally.

## Data Source
The analysis is based on the dataset that has been uploaded to this repository.
